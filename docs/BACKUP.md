# Резервная копия пультов

Самый простой способ — открыть веб-страницу хаба и нажать «Скачать backup JSON». Файл содержит точные длительности импульсов ИК/RF и список голосовых действий. Храните его на компьютере, а не только на ESP32.

## Через USB

На Windows в каталоге скетча:

```powershell
py -m pip install -r requirements.txt
py remote_backup.py --port COM7 backup my-remotes.json
py remote_backup.py --port COM7 restore my-remotes.json
```

Замените `COM7` на порт из диспетчера устройств. Восстановление добавляет/заменяет обученные ИК/RF-команды из JSON — повторно нажимать кнопки оригинальных пультов не придётся. Перед ним закройте Arduino Serial Monitor, иначе порт будет занят. Голосовые действия после полного стирания пока нужно заново создать на веб-странице; их список остаётся в скачанном браузером JSON как памятка.

## Когда backup обязателен

- до включения `Erase All Flash Before Sketch Upload`;
- до изменения таблицы разделов `partitions.csv`;
- перед заменой ESP32;
- после обучения новых важных кнопок.

Файл индивидуален. В публичный GitHub его добавлять не нужно.
