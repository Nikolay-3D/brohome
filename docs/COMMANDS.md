# Голосовые команды

Команда начинается со слова «Бро». После него можно сделать короткую паузу.

## Системные команды

| Фраза | Результат |
|---|---|
| «Бро, время» | Московское время |
| «Бро, который час» | Московское время |
| «Бро, погода» | Текущая температура в Москве |
| «Бро, температура» | Текущая температура в Москве |

## Свет в нашей демонстрационной конфигурации

Эти фразы создаются как действия на HTTP-странице хаба; они не зашиты в чужие радиокоды репозитория.

| Фраза | Сигналы |
|---|---|
| «Бро, свет» | `1A + 1B`, обе половины кухонной люстры |
| «Бро, малый свет» | `1A`, малая половина кухни |
| «Бро, большой свет» | `1B`, большая половина кухни |
| «Бро, полный свет» | `1A + 1B` |
| «Бро, свет в комнате» | `2A + 2B`, обе половины комнатной люстры |
| «Бро, малый свет в комнате» | `2A` |
| «Бро, большой свет в комнате» | `2B` |
| «Бро, полный свет в комнате» | `2A + 2B` |

Клавиши работают как переключатели. Хаб передаёт тот же сигнал, что оригинальный пульт, и не знает физическое состояние лампы.

## ТВ-приставка через ИК

- «Бро, приставка» или «Бро, включи приставку» — `pwr`;
- «Бро, громче», «Бро, тише», «Бро, выключи звук»;
- «Бро, домой», «Бро, назад», «Бро, ОК»;
- «Бро, включи 62» или «Бро, шестьдесят второй канал»;
- названия из `app/channels.json`, например «Бро, ТНТ».

Цифры многозначного канала отправляются с паузой 450 мс, чтобы приставка не теряла вторую цифру. Для работы названия обучите ИК-команды `0`…`9`; для остальных действий — `pwr`, `Vol_up`, `Vol_down`, `Mute`, `Home`, `Back`, `ok` с тем же регистром.

## Любые будущие устройства

На веб-странице ESP32:

1. обучите одну или несколько ИК/RF-команд;
2. в разделе голосовых действий укажите устройство, комнату и действие;
3. выберите до восьми команд одного типа;
4. перечислите фразы через запятую;
5. сохраните и нажмите «Тест».

Так можно добавить карниз, кондиционер или новый свет без изменения Python-кода. Для кондиционеров с длинным пакетным состоянием обучение нужно проверять на конкретной модели.
