# Если что-то не работает

Для общей проверки Linux-сервера из папки проекта выполните:

```bash
bash scripts/diagnose.sh
```

Скрипт проверит архитектуру, Python, ALSA, службу BroHome, порт 5001 и покажет последние строки журнала.

## Windows-мастер не видит Arduino CLI

Сначала установите Arduino IDE 2 с официального сайта и запустите её хотя бы один раз. Мастер ищет `arduino-cli.exe` в `PATH`, в `Program Files` и в локальной папке установки Arduino IDE. Arduino IDE 1.x не подходит для автоматического сценария.

## ESP не появляется среди COM-портов

Используйте USB-кабель с передачей данных, попробуйте другой USB-порт и закройте Serial Monitor. Если Windows показывает неизвестное устройство, установите драйвер USB-UART, соответствующий микросхеме именно вашей DevKit-платы. На плате с native USB иногда требуется удерживать `BOOT`, кратко нажать `RST`, затем отпустить `BOOT`.

## Хаб не появляется в Wi-Fi

Проверьте `secrets.h`, диапазон 2,4 ГГц и Serial Monitor 115200. Резервная точка доступа запускается при неудачном подключении; её имя задаёт `BROHOME_AP_SSID`. Синий индикатор означает попытку Wi-Fi, фиолетовый — Wi-Fi уже есть, но сервер недоступен.

## В браузере `Failed to fetch`

Убедитесь, что телефон не переключился с Wi-Fi хаба на мобильный Интернет, откройте страницу заново по текущему IP и запускайте только одно обучение. Во время RF-обучения веб-интерфейс может отвечать с задержкой; новая версия опрашивает результат отдельно.

## RF не обучается

- Проверьте нумерацию E07-M1101D и питание строго 3,3 В.
- Используйте модуль и пульт на 433,92 МГц.
- Уберите антенну от USB, MAX98357A и динамика.
- Нажмите кнопку один раз после появления режима обучения.
- Rolling-code пульты простым повтором не поддерживаются.

## ИК видно только вблизи

Направьте головку светодиода точно на приставку. Камера телефона видит большинство, но не все ИК-светодиоды. Для нескольких метров нужен транзисторный драйвер; питание одного лишь GPIO недостаточно. Не подавайте 5 В на GPIO ESP32.

## Канал получает только первую цифру

Обучите отдельные команды с именами `0`…`9`. Текущий сервер делает паузу 450 мс между цифрами. Если конкретная приставка медленнее, увеличьте `time.sleep(0.45)` в `app/command.py`.

## Хаб молчит

MAX98357A: `VIN=5V`, `SD=3V3`, общая земля; динамик подключён между `+` и `-` усилителя. После изменения проводов полностью снимите и снова подайте питание. Ярко-синий индикатор означает, что ESP32 получает звук от сервера.

## «Бро» или «Кухня» слышит, команду — нет

Проверьте Интернет сервера и журналы: `journalctl -u brohome-wifi.service -f`. Слова активации работают локально, но полная фраза распознаётся через Google. Микрофон INMP441 должен иметь `L/R=GND`.

Сервер записывает рядом с результатом Vosk уровень фрагмента в dBFS. При слишком тихой дальней речи увеличьте `BROHOME_MIC_GAIN` не выше `4.0`; ограничитель защищает пики от жёсткого клиппинга. Встроенный фильтр 100 Гц подавляет гул питания, вентилятора и вибрации, не требуя изменения прошивки ESP32.

## Диагностика сервера

```bash
systemctl status brohome-wifi.service --no-pager
journalctl -u brohome-wifi.service -n 100 --no-pager
ss -ltn | grep 5001
```
