# Как работает BroHome

ESP32 выполняет две независимые роли. Как автономный пульт он хранит импульсы в LittleFS и может обучать/посылать их из браузера даже без сервера. Как голосовой терминал он постоянно передаёт звук INMP441 на BroHome по TCP 5001 и принимает PCM-звук для динамика.

Перед Vosk сервер подавляет низкочастотный гул двухступенчатым фильтром 100 Гц, усиливает тихую речь и ограничивает пики, чтобы не допустить перегрузку. Vosk локально ищет слова активации «Бро» или «Кухня» и несколько устойчивых вариантов их распознавания. После пробуждения короткий фрагмент распознаётся через Google Speech Recognition. `command.py` сначала ищет пользовательское действие, полученное с хаба, затем системную команду, погоду или ИК-команду. Результат возвращается хабу по HTTP, а голосовой ответ — по уже открытому TCP-соединению.

## Хранилища

| Где | Что хранится |
|---|---|
| ESP32 LittleFS | ИК/RF-импульсы, голосовые действия, короткие локальные WAV |
| `app/channels.json` | Соответствие названий телеканалов номерам |
| `hub_automations.json` на сервере | Временная синхронизированная копия действий подключённых хабов |
| JSON backup пользователя | Переносимая копия обученных импульсов и действий |

Обычная загрузка скетча не стирает LittleFS при выключенной опции полного стирания flash. Но резервная копия всё равно обязательна.

## Сетевые порты

- TCP 5001 на сервере — двусторонний аудиоканал ESP32;
- HTTP 80 на ESP32 — веб-интерфейс и API управления;
- исходящий HTTPS сервера — распознавание Google и погода Open-Meteo.

Ни один из локальных портов не следует публиковать в Интернет.
