# Установка с нуля

Если вы раньше не работали с Git, Linux или ESP32, сначала откройте [«Начните здесь»](../START_HERE.md). Ниже приведён более короткий маршрут для опытной установки.

В готовом Release-архиве сначала откройте `OPEN-ME-FIRST.txt`. Для запуска предусмотрены корневые файлы `INSTALL-SERVER-LINUX.sh` и `FLASH-ESP32-WINDOWS.cmd`.

## 1. Подготовить сервер

Нужен включённый постоянно компьютер x86-64 с Debian/Ubuntu, Python 3.10–3.12, доступом в Интернет и домашнюю Wi-Fi-сеть. Raspberry Pi ARM пока не поддерживается вложенным набором wheel-файлов.

```bash
git clone https://github.com/Nikolay-3D/brohome.git
cd brohome
sudo bash install.sh
```

Установщик поставит системные пакеты, скопирует приложение в `~/brohome`, создаст Python-окружение из вложенных wheel-файлов и запустит `brohome-wifi.service`. При повторной установке прежний каталог сохраняется рядом с отметкой времени. Git не обязателен: эти же команды работают в архиве **Code → Download ZIP**.

Проверка:

```bash
systemctl status brohome-wifi.service --no-pager
journalctl -u brohome-wifi.service -f
hostname -I
```

Если установка запускается не через обычный `sudo`, укажите пользователя явно: `sudo ./install.sh --user ivan`.

## 2. Настроить и прошить ESP32

Соберите [схему](WIRING.md). В каталоге скетча скопируйте `secrets.example.h` в `secrets.h` и замените:

- `YOUR_WIFI_NAME` — имя домашнего Wi-Fi;
- `YOUR_WIFI_PASSWORD` — пароль Wi-Fi;
- `192.168.1.100` — адрес Linux-сервера из `hostname -I`;
- `kitchen` — уникальное имя этого хаба;
- пароль резервной точки доступа — не менее восьми символов.

На Windows проще запустить мастер из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\flash-esp32.ps1
```

Он установит ядро и библиотеки, создаст локальный `secrets.h`, соберёт скетч и предложит выбрать COM-порт. Ручной вариант описан в [инструкции прошивки](../esp32/esp32-s3-devkitc-1/brohome_control_hub/README.md). Не включайте полное стирание flash после обучения без JSON-копии.

## 3. Найти веб-страницу хаба

Посмотрите список клиентов в роутере или Serial Monitor 115200. Откройте `http://IP_ХАБА/`. Если домашний Wi-Fi недоступен, подключитесь к резервной точке с именем из `BROHOME_AP_SSID` и откройте `http://192.168.4.1/`.

## 4. Обучить пульты

- ИК: направьте оригинальный пульт на приёмник с 10–30 см, начните обучение и один раз нажмите кнопку.
- RF: отнесите антенну от USB и усилителя, начните обучение и один раз уверенно нажмите кнопку пульта.
- После каждого сохранения нажмите «Отправить» и проверьте реальное устройство.
- Используйте короткие ASCII-имена: `pwr`, `1A`, `room_big`.

## 5. Создать голосовые действия

В нижней части веб-страницы заполните устройство, комнату, действие и фразы. Для сцены выделите несколько команд одного типа. Хаб сам передаст реестр серверу; ручное редактирование серверной конфигурации не требуется.

## 6. Сразу сделать backup

Нажмите «Скачать backup JSON» и сохраните файл на компьютере/в резервной копии. Подробности — [BACKUP.md](BACKUP.md).

## Обновление и удаление

```bash
cd brohome
git pull --ff-only
sudo bash install.sh
```

Удалить службу, сохранив файлы: `sudo ./uninstall.sh`. Полное удаление требует явного `--purge --install-dir /точный/путь`.
