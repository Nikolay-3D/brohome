# Схема подключения

Перед монтажом отключите USB. Все модули должны иметь общую землю.

## Таблица соединений

| Модуль | Контакт | ESP32-S3 / питание |
|---|---|---|
| ИК-приёмник | `OUT` / `DAT` | `GPIO4` |
|  | `VCC` | `3V3` |
|  | `GND` | `GND` |
| ИК-передатчик-модуль | `DAT` | `GPIO5` |
|  | `VCC` | `5V` — только если это допускает модуль |
|  | `GND` | `GND` |
| E07-M1101D | №1 `GND` | `GND` |
|  | №2 `VCC` | **только `3V3`** |
|  | №3 `GDO0` | `GPIO9` |
|  | №4 `CSN` | `GPIO10` |
|  | №5 `SCK` | `GPIO12` |
|  | №6 `MOSI` | `GPIO11` |
|  | №7 `MISO/GDO1` | `GPIO13` |
|  | №8 `GDO2` | не подключать |
| INMP441 | `SCK` | `GPIO6` |
|  | `WS` | `GPIO7` |
|  | `SD` | `GPIO15` |
|  | `L/R` | `GND` |
|  | `VDD` | `3V3` |
|  | `GND` | `GND` |
| MAX98357A | `BCLK` | `GPIO16` |
|  | `LRC` / `WS` | `GPIO17` |
|  | `DIN` | `GPIO18` |
|  | `VIN` | `5V` |
|  | `SD` | `3V3` или штатная подтяжка модуля |
|  | `GND` | `GND` |
| RGB, общий катод | `R` через 220–330 Ом | `GPIO3` |
|  | `G` через 220–330 Ом | `GPIO14` |
|  | `B` через 220–330 Ом | `GPIO8` |
|  | общий катод | `GND` |

Динамик подключается к клеммам `+` и `-` MAX98357A. Ни один его провод не подключается к GND.

## Нумерация CC1101

У E07-M1101D подписи могут отсутствовать. Определяйте вывод №1 по рисунку именно для того вида платы, который указан в даташите. Не угадывайте по фотографии обратной стороны. Подача 5 В на VCC CC1101 почти наверняка повредит модуль.

## ИК-дальность

Передатчик должен смотреть головкой на окно приёмника приставки. Для уверенных 2–5 метров применяйте готовый модуль с транзистором либо эту принципиальную цепь:

```text
GPIO5 ── 1 кОм ── база NPN
                   эмиттер ── GND
5V ── резистор ── ИК LED ── коллектор
```

Номинал резистора ИК-светодиода и допустимый импульсный ток выбираются по его даташиту. GPIO управляет только базой транзистора.

## Размещение

- Отнесите CC1101 и его антенну от USB-кабеля, усилителя и проводов динамика.
- Поверните микрофон отверстием в сторону комнаты.
- Не закрывайте ИК-светодиод непрозрачным корпусом.
- GPIO19/20 оставьте для native USB, GPIO35–37 заняты OPI PSRAM.
