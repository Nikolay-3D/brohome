# Перечень деталей

| Количество | Деталь | Примечание |
|---:|---|---|
| 1 | ESP32-S3 DevKitC-1, модуль N16R8 | 16 МБ flash, 8 МБ OPI PSRAM |
| 1 | E07-M1101D / CC1101 433 МГц | Версия на 433,92 МГц с антенной |
| 1 | ИК-приёмник 38 кГц | Готовый модуль с `OUT`, `VCC`, `GND` |
| 1 | ИК-передатчик | Лучше готовый 5-вольтовый модуль с транзисторным драйвером |
| 1 | INMP441 | Цифровой I2S-микрофон |
| 1 | MAX98357A | I2S моноусилитель |
| 1 | Динамик 4–8 Ом, до 3 Вт | Подключается только к выходам усилителя |
| 1 | RGB-светодиод с общим катодом | Либо соответствующий готовый модуль |
| 3 | Резистор 220–330 Ом | По одному в цепи каждого цвета RGB |
| 1 | Блок питания USB 5 В, от 1 А | Качественный, с коротким кабелем |
| — | Макетная/монтажная плата, провода, корпус | Все земли соединяются вместе |

Если используется отдельный ИК-светодиод, а не модуль, добавьте NPN-транзистор 2N2222/S8050, резистор базы около 1 кОм и токоограничивающий резистор светодиода. Не включайте мощный ИК-светодиод прямо между GPIO и землёй.

Для постоянной установки пайка или винтовые клеммы надёжнее беспаечной макетки. Вторая макетная плата не обязательна: нужные GPIO в этой схеме выбраны на доступной стороне DevKitC.
