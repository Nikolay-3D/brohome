# Световая индикация

Прошивка рассчитана на RGB-светодиод с общим катодом.

| Цвет | Состояние |
|---|---|
| Не горит | Нет питания, оборван общий провод или контроллер не работает |
| Белый | Загрузка и проверка модулей |
| Синий | Подключение к домашнему Wi-Fi |
| Фиолетовый | Wi-Fi есть, но голосовой сервер BroHome недоступен |
| Зелёный | Хаб готов и слушает слово «Бро» |
| Ярко-синий / голубой | Воспроизводится голосовой ответ |
| Оранжевый / жёлтый | Обучение ИК- или RF-команде |
| Красный | Ошибка инициализации или обучения |

Фактический оттенок зависит от RGB-модуля и резисторов. Если красный и синий перепутаны, проверьте, что R подключён к GPIO3, G к GPIO14, B к GPIO8.
