# Начните здесь: BroHome с нуля

Эта инструкция рассчитана на человека, который не знаком с Git и раньше не прошивал ESP32. Выполняйте шаги по порядку и не переходите дальше, пока текущая проверка не прошла.

После распаковки архива сначала откройте обычный текстовый файл `OPEN-ME-FIRST.txt`. Два запускаемых файла находятся прямо рядом с ним: `INSTALL-SERVER-LINUX.sh` для сервера и `FLASH-ESP32-WINDOWS.cmd` для ESP32.

## Что получится

После установки кухонный хаб сможет:

- услышать слова «Бро» и «Кухня»;
- передать речь домашнему Linux-серверу;
- управлять приставкой и телевизором через ИК;
- управлять светом через CC1101 433,92 МГц;
- произнести ответ через собственный динамик;
- обучаться пультам через обычную веб-страницу;
- сохранить обученные команды в JSON на компьютере.

## 1. Подготовьте два компьютера

Нужны:

1. Обычный Windows-компьютер для прошивки ESP32 по USB.
2. Постоянно включённый компьютер x86-64 с Debian или Ubuntu для голосового сервера.

Raspberry Pi и другие ARM-компьютеры пока не поддерживаются готовым автономным набором Python-пакетов.

## 2. Скачайте проект без Git

Откройте [последний установочный выпуск](https://github.com/Nikolay-3D/brohome-control-hub/releases/latest), скачайте файл `brohome-control-hub-<версия>.zip`, распакуйте его и не переносите отдельные файлы из папок. Все относительные пути должны сохраниться.

Если выпуск ещё не создан, на странице проекта можно нажать **Code → Download ZIP**.

Если Git уже установлен, вместо ZIP можно выполнить:

```bash
git clone https://github.com/Nikolay-3D/brohome-control-hub.git
```

## 3. Купите и проверьте детали

Откройте [перечень деталей](docs/BOM.md). Особенно проверьте:

- ESP32-S3 должна быть версией N16R8: 16 МБ flash и 8 МБ OPI PSRAM;
- CC1101 должен быть рассчитан на 433,92 МГц;
- динамик подключается через MAX98357A, а не прямо к ESP;
- для дальнего ИК нужен передатчик с транзисторным драйвером;
- блок питания USB должен выдавать стабильные 5 В и не менее 1 А.
- USB-кабель должен передавать данные, а не только заряжать.

## 4. Соберите хаб без питания

Полностью отключите USB и соедините модули по [таблице подключения](docs/WIRING.md).

Сначала подключайте по одной группе:

1. ИК-приёмник и ИК-передатчик.
2. CC1101.
3. Микрофон INMP441.
4. Усилитель MAX98357A и динамик.
5. RGB-светодиод с тремя резисторами.

Перед первым включением ещё раз проверьте питание:

- CC1101 и INMP441 — только 3,3 В;
- MAX98357A и допустимый 5-вольтовый ИК-модуль — 5 В;
- все земли объединены;
- ни один вывод ESP не соединён напрямую с 5 В;
- динамик находится между `+` и `-` MAX98357A, а не между выходом и GND.

## 5. Установите голосовой сервер

Перенесите всю распакованную папку проекта на Debian/Ubuntu-компьютер, откройте в ней терминал и выполните:

```bash
bash INSTALL-SERVER-LINUX.sh
```

Установщик сам поставит системные зависимости, создаст отдельное Python-окружение и службу `brohome-wifi.service`.

Узнайте IP-адрес сервера:

```bash
hostname -I
```

Запишите первый адрес домашней сети, например `192.168.1.148`. Он понадобится при прошивке ESP.

Проверка сервера:

```bash
systemctl status brohome-wifi.service --no-pager
```

В строке `Active:` должно быть `active (running)`. Если это не так, выполните:

```bash
bash scripts/diagnose.sh
```

## 6. Прошейте ESP32 с Windows

1. Установите [Arduino IDE 2](https://www.arduino.cc/en/software).
2. Подключите ESP32-S3 к Windows-компьютеру USB-кабелем с передачей данных.
3. Дважды щёлкните `FLASH-ESP32-WINDOWS.cmd` в корне распакованной папки.

Если Windows не разрешает двойной щелчок, откройте PowerShell в этой папке и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\flash-esp32.ps1
```

Мастер:

- найдёт Arduino CLI внутри Arduino IDE;
- установит ядро ESP32 и нужные библиотеки;
- попросит имя и пароль Wi-Fi;
- попросит IP Linux-сервера;
- создаст локальный `secrets.h`, который не публикуется;
- покажет COM-порты;
- соберёт и загрузит прошивку без полного стирания flash.

Пароль Wi-Fi при вводе не отображается. Не отправляйте файл `secrets.h` другим людям и не добавляйте его на GitHub.

## 7. Найдите веб-страницу ESP

После перезагрузки найдите новый клиент в интерфейсе роутера и откройте:

```text
http://IP_ESP/
```

Если ESP не подключилась к домашнему Wi-Fi, подключитесь к резервной точке доступа с именем и паролем, указанными мастеру, и откройте `http://192.168.4.1/`.

## 8. Проверьте модули по одному

1. При запуске должен прозвучать короткий сигнал.
2. RGB-индикатор должен перейти из режима подключения в рабочий режим.
3. Обучите одну ИК-команду и нажмите «Отправить».
4. Обучите одну RF-команду и нажмите «Отправить».
5. Произнесите: «Кухня, время».

Если какой-либо этап не прошёл, не переобучайте всё заново — откройте [диагностику](docs/TROUBLESHOOTING.md) и исправьте именно этот модуль.

## 9. Обучите пульты и голосовые действия

На веб-странице ESP:

1. Выберите ИК, сырую ИК-запись или 433 МГц.
2. Введите короткое латинское имя команды.
3. Нажмите «Начать обучение».
4. Один раз нажмите нужную кнопку оригинального пульта.
5. Сразу проверьте команду кнопкой «Отправить».
6. В нижнем блоке привяжите одну или несколько команд к голосовой фразе.

Для RC5/RC6 выбирайте 36 кГц, для большинства NEC-пультов — 38 кГц, для Sony — 40 кГц. Если протокол неизвестен, начните с обычного ИК и 38 кГц.

## 10. Сохраните пульты

После обучения нажмите **Скачать backup JSON** и сохраните файл отдельно от ESP. Это позволит восстановить команды после полного стирания памяти.

Не публикуйте домашний backup: RF-коды и названия устройств могут быть личными данными.

## Что делать при обновлении

Сначала скачайте backup JSON. Затем загрузите новую версию проекта и снова запустите мастер прошивки. Обычная загрузка с выключенным полным стиранием сохраняет команды, но резервная копия всё равно обязательна.

На Linux-сервере из обновлённой папки выполните:

```bash
bash INSTALL-SERVER-LINUX.sh
```

Установщик сохранит предыдущую установку рядом с отметкой времени.
