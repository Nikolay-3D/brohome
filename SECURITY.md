# Безопасность

Никогда не публикуйте:

- `secrets.h` с именем и паролем Wi-Fi;
- SSH-пароли, закрытые ключи и токены;
- `hub_automations.json`, если названия комнат и устройств считаются личными;
- JSON-копии пультов, если вы не хотите раскрывать радиокоды своих устройств;
- записи микрофона (`voice_full.wav`).

Эти файлы уже исключены через `.gitignore`. Перед публикацией запустите:

```bash
python3 scripts/check_public_tree.py
```

HTTP-интерфейс хаба не имеет аутентификации и предназначен только для доверенной домашней сети. Задайте уникальный пароль резервной точки доступа в `secrets.h`, не пробрасывайте TCP 5001 и HTTP 80 в Интернет и используйте отдельную IoT-сеть, если роутер это поддерживает.

Об уязвимости сообщайте владельцу репозитория приватно через GitHub Security Advisories, не создавая публичный issue с секретами или готовым эксплойтом.
