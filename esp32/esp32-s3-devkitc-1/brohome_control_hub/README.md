# Прошивка BroHome Control Hub

Это основной скетч для ESP32-S3 DevKitC-1 N16R8. Полная схема находится в [docs/WIRING.md](../../../docs/WIRING.md).

## 1. Подготовить Arduino IDE

### Простой автоматический способ для Windows

Установите Arduino IDE 2, подключите ESP32 и из корня проекта выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\flash-esp32.ps1
```

Мастер сам установит указанные ниже версии ядра и библиотек, создаст локальные настройки, соберёт и загрузит прошивку. Ручные шаги ниже нужны только если мастер использовать нельзя.

### Ручной способ

Установите поддержку плат Espressif ESP32 и библиотеки через Library Manager:

- IRremote 4.7.1;
- RadioLib 7.6.0.

Откройте `brohome_control_hub.ino`. Файл `partitions.csv` должен оставаться рядом со скетчем.

## 2. Создать локальные настройки

Скопируйте `secrets.example.h` в `secrets.h` и заполните значения. Настоящий `secrets.h` исключён из Git. Адрес сервера — это адрес Linux-компьютера, где запущен BroHome.

## 3. Выбрать плату

```text
Board: ESP32S3 Dev Module
Flash Size: 16MB (128Mb)
PSRAM: OPI PSRAM
USB CDC On Boot: Disabled/default
Upload Mode: UART0 / Hardware CDC
Erase All Flash Before Sketch Upload: Disabled
```

Обычная прошивка с выключенным полным стиранием сохраняет обученные команды. Перед изменением таблицы разделов или полным стиранием обязательно скачайте JSON backup.

## 4. Первый запуск

Откройте Serial Monitor 115200. После подключения к домашнему Wi-Fi там появится IP-адрес. Откройте его в браузере. Если домашняя сеть недоступна, подключитесь к резервной точке с именем и паролем из `secrets.h`, затем откройте `http://192.168.4.1/`.

На странице можно:

- обучать, тестировать и удалять ИК/RF-команды;
- объединять до восьми сигналов одного типа в голосовое действие;
- скачивать JSON-копию пультов;
- видеть, какие действия сервер получает автоматически.

## Обучение

Для ИК держите оригинальный пульт в 10–30 см от приёмника. Перед обучением выберите несущую частоту: 36 кГц для RC5/RC6, 38 кГц для NEC и большинства бытовых пультов, 40 кГц для Sony либо 56 кГц для соответствующих устройств. Частота сохраняется отдельно в каждой команде и используется при воспроизведении; обычный демодулирующий ИК-приёмник сам измерить её не может. Для сложных протоколов выберите «ИК — сырая запись» и один раз коротко нажмите оригинальную кнопку. Хаб напрямую запишет переходы на выходе ИК-приёмника с микросекундной точностью, сохранит 32-битные длительности и воспроизведёт поток один раз без декодирования, разбиения на кадры и повторов. Для RF уберите антенну CC1101 подальше от USB и усилителя. Нажимайте кнопку только после запуска обучения. Сразу проверяйте сохранённую команду кнопкой «Отправить».

Имена содержат только латинские буквы, цифры, `_` и `-`, максимум 48 символов. Для ТВ предусмотрены имена `0`…`9`, `pwr`, `Vol_up`, `Vol_down`, `Mute`, `Home`, `Back`, `ok`.

## USB-инструмент

```powershell
py -m pip install -r requirements.txt
py remote_backup.py --port COM7 backup my-remotes.json
py remote_backup.py --port COM7 restore my-remotes.json
py remote_backup.py --port COM7 command "list"
```

Закройте Serial Monitor перед запуском. Замените `COM7` на настоящий порт.

## Локальные звуки

В каталог включены короткие WAV-сигналы загрузки/обучения. Их можно загрузить через `audio-put`. Основные ответы постоянно хранить на ESP не требуется: сервер передаёт их в реальном времени.

Поддерживается PCM WAV mono 16 bit, 8–48 кГц:

```powershell
py remote_backup.py --port COM7 audio-put ready ready.wav
```

## Ограничения

RF рассчитан на распространённые OOK/ASK-пульты с фиксированным кодом. Rolling code не клонируется. Для большой ИК-дальности используйте транзисторный драйвер, а не отдельный светодиод напрямую от GPIO.
