BROHOME - WHAT TO RUN FIRST
===========================

Этот архив содержит проект умного дома BroHome и две его основные части:

1. Голосовой сервер для Debian/Ubuntu x86-64.
2. Прошивку контроллера ESP32-S3.

Это не обычная Windows-программа с одним EXE-файлом: сервер постоянно работает
на Linux-компьютере, а Windows используется для настройки и прошивки ESP32 по USB.


ПЕРВАЯ УСТАНОВКА
----------------

ШАГ 1. СНАЧАЛА УСТАНОВИТЕ LINUX-СЕРВЕР

1. Скопируйте ВСЮ распакованную папку на компьютер с Debian/Ubuntu x86-64.
2. Откройте терминал в этой папке.
3. Выполните:

   bash INSTALL-SERVER-LINUX.sh

4. После установки выполните:

   hostname -I

5. Запишите IP-адрес сервера, например 192.168.1.148.


ШАГ 2. ЗАТЕМ ПРОШЕЙТЕ ESP32 НА WINDOWS

1. Установите Arduino IDE 2: https://www.arduino.cc/en/software
2. Подключите ESP32-S3 к Windows USB-кабелем с передачей данных.
3. Дважды щёлкните файл:

   FLASH-ESP32-WINDOWS.cmd

4. Введите имя и пароль Wi-Fi, IP Linux-сервера из шага 1 и выберите COM-порт.
5. Дождитесь сообщения Done. Не отключайте USB во время загрузки.


ШАГ 3. ОТКРОЙТЕ ВЕБ-СТРАНИЦУ ESP

Найдите ESP в списке клиентов роутера и откройте в браузере:

   http://IP_ESP/

После этого обучите одну ИК-команду, одну команду света и проверьте фразу
"Кухня, время". Обязательно скачайте backup JSON обученных пультов.


ПОДРОБНАЯ ИНСТРУКЦИЯ
--------------------

Откройте файл START_HERE.md на GitHub или в редакторе Markdown:
https://github.com/Nikolay-3D/brohome/blob/main/START_HERE.md

Если сервер BroHome уже установлен, шаг 1 можно пропустить и использовать его
существующий IP-адрес.
